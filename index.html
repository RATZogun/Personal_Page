Esta página pessoal foi construída em duas versões com o mesmo conteúdo. O que muda entre elas é apenas o framework CSS usado na interface. Escolha qual quer visitar.

Versão 1

Bootstrap 5

Framework de componentes prontos. A interface é montada com a grade, os cartões, a barra de navegação e os utilitários da própria biblioteca.

  • Tema por meio do atributo data-bs-theme
  • Grade responsiva de 12 colunas
  • Componentes e ícones da biblioteca
Abrir a versão Bootstrap → Versão 2

Tailwind CSS 4

Framework de utilitários. Não existem componentes prontos: cada peça é composta por classes pequenas, e o CSS final é gerado sob medida.

  • Tema pela classe dark no elemento raiz
  • Layout com utilitários de grade e flexbox
  • CSS compilado pelo Tailwind CLI, sem CDN
Abrir a versão Tailwind →
